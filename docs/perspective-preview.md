# Unlisted perspective preview

Open `/perspectives.html` to use the production interface with `lab=perspectives`. This is discoverable by URL, not access-controlled. It requests no indexing and has no public navigation entry.

The preview consumes the same published datasets and assessment engine as the public routes. It does not poll vendor endpoints. Routine data publications therefore update the preview automatically.

Perspective is a presentation preference, not a permission, entitlement or availability assertion. The provisional views are decision overview, security and compliance, platform and data operations, application observability, and all perspectives. They currently organize Cloud Environment guidance only. Product and environment filters remain explicit; perspective never silently changes them. All matching records remain in the full comparison and unresolved conflicts stay prominent. Print output retains complete evidence alongside prioritized content.

Before wider adoption, maintenance should review explicit capability-to-perspective mappings, unmatched new capabilities, evidence scope, conflicting guidance, shared URLs, both themes and print readability. Taxonomy should evolve from maintained content; a separate Network perspective is not justified by the current coverage. These are preview review criteria, not a change to live task schedules.
