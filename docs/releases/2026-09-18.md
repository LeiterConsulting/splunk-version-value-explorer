# September 18, 2026

## Summary

Version Compass added Splunk IT Service Intelligence 5.0.2, published on Splunkbase on September 17, 2026. The route now covers the maintenance release's MCP pagination, reliability fixes, bundled-library baseline, and validation work without changing the documented ITSI 5.0 platform-line gate.

## What changed

### IT Service Intelligence 5.0.2

- Added 5.0.2 as the latest ITSI release target and the default customer-managed ITSI destination.
- Added stateless `count` and `offset` pagination for `SA-ITOA_get_episodes`, `SA-ITOA_get_impacted_objects`, and `SA-ITOA_get_external_links`.
- Added customer-facing reliability coverage for episode-policy actions, Episode Event Timeline column order, multiline comments, NATS worker recovery, and HTTPS webhook certificate verification.
- Recorded the updated ITSI-bundled library baseline separately from customer-owned apps and packages.

## Customer-facing impact

Teams can now assess the 5.0.1-to-5.0.2 maintenance move directly. Deployments using the affected MCP tools should validate multi-page retrieval, while deployments affected by the fixed event and integration issues can plan targeted regression tests.

## Compatibility, readiness, and breaking-change implications

- The customer-managed Enterprise gate remains the official ITSI 5.0 matrix line: Splunk Enterprise 10.2 or 10.4. Version Compass does not invent a new patch-level platform floor for 5.0.2.
- Splunk Cloud Platform service details still publish ITSI 5.0 with Cloud 10.5. Version Compass therefore treats 5.0.2 Cloud availability as Splunk-managed and stack-, region-, entitlement-, and schedule-dependent.
- Pagination is an additive capability. No new 5.0.2 breaking change is claimed.
- The bundled-library update is product-owned; the guidance does not instruct customers to replace Splunk-bundled packages independently.
