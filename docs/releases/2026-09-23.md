# September 23, 2026 — ES editions evidence and prerequisite corrections

The public ES Essentials/Premier comparison now includes task-level agent prerequisites and makes additional official-source disagreements visible. This is a documentation audit, not a newly announced ES release or a claim that every source changed today.

## Customer-facing changes

- Automation Builder now includes Cloud Platform 10.1+, paired SOAR Cloud, Splunk-account requirements and the documented FedRAMP SOAR exclusion. Connector Builder includes platform 10.1+, paired SOAR Cloud and App/Asset Edit permissions. Its edition conflict remains unresolved.
- AI SOC Analyst and Malware Reversing/Phishing now show the differing ES minimums in the aggregate table and individual 8.7 task guides. The comparison does not certify the lower baseline or change edition entitlement.
- Current pricing guidance distinguishes the ES page's activity-based option from the detailed FAQ's Cloud Platform scope. The former SOAR seat-pricing assertion is removed because the current page no longer specifies it; no contractual change is inferred.
- Exposure Analytics' continuous posture metrics and Entity Profiling remain marked as coming soon, distinct from entity discovery and change history.
- Five source questions are shown with both sides cited. Connector Builder and Guided Response retain their original, distinct qualifications.

## Affected routes and boundaries

Applies to `?view=es-editions`, its legacy `?preview=es-editions` alias, and both default and optional `theme=cisco` appearances, including print/PDF reports. Public navigation and independent Version Compass branding remain intact. All 20 capabilities and selected historical release entries remain in the print report, with numbered citations and a source directory.

No product release identifiers, Enterprise platform gates, Cloud-managed availability rules, main Release Guide datasets, lifecycle-policy review dates, WebMCP tools or schemas change. No activation-verification controls are introduced. New prerequisites can affect readiness; conflicting minimums require Splunk clarification, not an inferred upgrade recommendation. No new software breaking change is asserted.
