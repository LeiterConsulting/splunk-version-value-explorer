# October 3, 2026 — Enterprise 10.6 upgrade routes

## Plain-language summary

Splunk's canonical Enterprise 10.6 upgrade page now publishes an explicit **Upgrade paths to version 10.6** table. Version Compass no longer leaves Enterprise and Heavy Forwarder 10.6 routes unknown: 9.4.x first moves to 10.0.x or 10.2.x, while 10.0.x, 10.2.x and 10.4.x have listed paths to 10.6.x. This correction does not fill adjacent evidence gaps. Exact maintenance versions, operating systems, apps, topologies, Cloud rollout, entitlement, region and authorization also remain separate checks.

Live parity verification caught and repaired one source-attribution defect before final sign-off: Heavy Forwarder 10.6 steps now retain the exact versioned 10.6 upgrade-table source in the screen report, saved report, source register and read-only WebMCP output. The older 10.4 source remains attached only to its historical scope.

No newer maintained Enterprise, Cloud, Enterprise Security, ITSI, Observability, Forwarder or SOAR release was found in the complete official source inventory. SOAR 8.7.0 remains build 243 rather than affected build 232 and requires Python 3.13-compatible automation. The Splunk advisory index still announces October 7, 2026 as the next publication date.
