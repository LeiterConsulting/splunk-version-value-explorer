## Python instrumentation 2.13.3

Advanced the maintained customer-managed Splunk OpenTelemetry Python baseline
from 2.13.2 to 2.13.3. The October 29 patch bundles dependencies separately for
CPython 3.10 through 3.14 in standard and SecureApp images for AMD64 and ARM64,
signs and verifies both image variants during publishing, adds PostgreSQL
query-to-trace correlation, raises the Requests floor to 2.33.0 and the wrapt
floor to 2.5.1, and loads declarative-configuration dependencies only when file
configuration is used. The final PyPI retry also no longer reports a false
publishing failure.

These are customer-managed instrumentation packaging, dependency and
correlation changes. They do not establish a Splunk Observability Cloud service
rollout, tenant or realm availability, entitlement, authorization, or universal
application compatibility. VersionCompass retains the 2.13.2 OpAMP-client
record in scoped history.

Source: [Splunk OpenTelemetry Python 2.13.3](https://github.com/signalfx/splunk-otel-python/releases/tag/v2.13.3), section **v2.13.3 release body**.
