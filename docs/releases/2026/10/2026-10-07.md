# October 7, 2026 — Version Release Watch

## Cloud 10.6 current service pairing

Splunk's current 10.6 Service Details table now pairs subscriptions with Splunk Cloud Platform 10.6, Enterprise Security 8.7 and ITSI 5.0. Version Compass advances its default Cloud, migration, ES, ITSI and Observability host context to that current service line. The pairing does not establish every selected stack, provider, region, feature, edition, entitlement, rollout schedule or regulated-environment authorization; those qualifications remain visible in the report.

## Published 10.6 forwarder receiver rows

The current Enterprise receiver matrix now includes the exact 10.6 forwarder row and receiver column. The Cloud supported-forwarder table now includes UF/HF 10.6.x directly connected to Cloud 10.6.x, while retaining the documented release-line differences for older forwarders. Version Compass replaces the prior 10.6 evidence-gap guard with those exact rows.

Enterprise receiver compatibility, Cloud direct compatibility, hybrid legs, an outgoing intermediate tier, Edge Processor, certificate renewal, OS packages, upgrade paths, support lifecycle, entitlement and authorization remain separate assessments. The omitted Cloud 10.4 pairing for forwarder 10.0 remains Not established.

The source-register generator retains stable source-to-claim mappings for UF/HF upgrade, Enterprise and Cloud receiver, topology, OS/package, certificate, issue, advisory and borrowed HF technical/runtime claims. Regression coverage now exercises the published 10.6 receiver rows without generalizing them to unlisted combinations.
