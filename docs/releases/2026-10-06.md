# October 6, 2026 — Version Release Watch

## Splunk OpenTelemetry Python 2.13.0

Splunk OpenTelemetry Python 2.13.0 was published October 5 after the prior daily review. Version Compass now records its customer-managed configuration and deployment boundaries:

- `OTEL_CONFIG_FILE` enables standard OpenTelemetry declarative configuration and changes precedence by preventing the Splunk distribution's environment-variable defaults from being applied. Splunk resource information and the `distribution.splunk` trace-response-header option remain integrated; profiling and callgraphs still require environment variables.
- Standard and SecureApp init images are now published for both AMD64 and ARM64. The selected image type, tag or digest and workload architecture still require deployment validation.
- The minimum `wrapt` dependency advances from 2.2.2 to 2.5.0, so locked application environments should be resolved and rebuilt before rollout.
- The ineffective `SPLUNK_OTEL_SYSTEM_METRICS_ENABLED` variable is removed from generated metadata. It never changed runtime behavior; `OTEL_PYTHON_DISABLED_INSTRUMENTATIONS=system_metrics` is the documented disable path.

These are customer-managed instrumentation changes, not an Observability Cloud SaaS release or proof of compatibility with every Python runtime, framework or application dependency set.
