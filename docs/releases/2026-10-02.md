# October 2, 2026 — Enterprise Security 8.7.1 and current Cloud evidence

## Plain-language summary

Splunk Enterprise Security 8.7.1 was published October 1, 2026. Version Compass keeps the stable 8.7 journey selector but now identifies the exact maintenance change: Connector Builder remains labeled Premier and is turned on for all eligible users. The separate Essentials-versus-Premier source conflict, SOAR pairing and permission prerequisites remain visible. AI SOC Analyst retains its separate Splunk-enablement requirement.

The freshly published Cloud Platform 10.6 Service Details page does not establish Cloud 10.6 rollout. Its current subscription table still lists Cloud 10.5, Enterprise Security 8.6 and ITSI 5.0. Its supported-forwarder table still stops at UF/HF 10.4.x, so direct or intermediate 10.6 receiver compatibility remains Not established.

SOAR Cloud and On-premises remain at 8.7.0. The On-premises correction remains build 243 rather than affected build 232, Python 3.13 remains required, and the documented pre-7.0 bridges are unchanged. The Splunk App for SOAR 8.7.0 table still names Enterprise Security 8.7.0 exactly; this review does not infer 8.7.1 compatibility from the adjacent ES release.
