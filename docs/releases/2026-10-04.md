# October 4, 2026 — ES Editions evidence review

## Plain-language summary

The complete ES Editions inventory was checked against all 20 maintained official public sources, then cross-checked against the exact Splunk App for SOAR 8.7.0, SOAR Export 8.7.0, SOAR 8.7 compatibility and SOAR Cloud 8.7 release records. No edition, entitlement, prerequisite, compatibility, pairing, regional or release-stage claim required a factual correction.

The public evidence remains intentionally non-normalized where Splunk's pages disagree. The ES 8.7 agent table still lists Connector Builder for Essentials and Premier, while the ES 8.7.1 release note assigns it to Premier. The ES 8.6 Guided Response task still supports Essentials and Premier, while the 8.7 capability matrix labels Triage and Guided Response enhancements under Premier. Workflow grouping is not entitlement, and licensing or independently current release numbers do not establish a supported ES–SOAR pairing.

# CSP and FedRAMP evidence review

## Plain-language summary

The complete Cloud-environment inventory was checked against all 10 maintained official sources, both CSP-owned SOAR sources, the exact FedRAMP Marketplace offerings and the rendered US Public Sector symbol table. No provider, region, service-experience, edition, compatibility, feature-availability, entitlement or authorization claim required a factual correction.

The current boundaries remain important: the 10.6 documentation path still lists Cloud 10.5, ES 8.6 and ITSI 5.0 as the current managed stack; Moderate and High remain separate offerings; and announcements do not establish universal rollout. The service table still excludes Federated Search for Amazon S3 in High and IL5, while the April 8 change log adds them for relevant 10.3 releases. The February 2026 visual matrix has a Moderate mark and a blank High cell, so the conflict remains visible rather than normalized.

SOAR-specific public evidence still establishes FedRAMP Moderate in AWS GovCloud with mandatory FIPS mode, playbook and Broker restrictions, automation isolation and no native-data migration. It does not establish SOAR Cloud FedRAMP High. The SOAR service description also still says “As of September 2026” while its 8.7.0 row says “April 2026”; both dates remain recorded.
